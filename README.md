# Книгарня

Програмна система для невеликої книгарні з торговим залом і онлайн-продажем.
Наскрізний навчальний проєкт з дисципліни «Технології розроблення програмних систем»
(КНУ імені Тараса Шевченка, ФІТ, група ПП-42, варіант 8).

## Призначення

Система замінює паперовий і табличний облік однією вебсистемою: каталог книг,
облік залишків, онлайн-замовлення та програма лояльності.

## Функціональність прототипу

- додавання книг до каталогу з перевіркою ISBN-13 і унікальності;
- пошук за назвою, автором або ISBN без урахування регістру;
- оформлення замовлення з перевіркою вільного залишку;
- розрахунок суми, знижок і бонусів (списання не більше 50 % суми).

## Технології

Python 3.12, FastAPI, SQLAlchemy 2, SQLite (розробка) / PostgreSQL 16 (продакшн), unittest.

## Структура

```
src/bookstore/
  domain/        бізнес-правила (ISBN, ціни, залишки)
  repositories/  доступ до БД
  services/      сценарії використання
  api/           схеми REST API
  main.py        застосунок FastAPI
tests/           автоматизовані тести
docs/            проєктна документація
```

## Запуск

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
PYTHONPATH=src python -m uvicorn bookstore.main:app --reload --host 127.0.0.1 --port 8080
```

Документація API: http://127.0.0.1:8080/docs

## Тести

```bash
PYTHONPATH=src python -m unittest discover -s tests -v
```
